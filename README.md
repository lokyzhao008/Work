# AI Video Workflow Studio
AI × 3D 工作流分享视频项目（16:9 横屏）

> 2026-10-23 项目资料同步区。此仓库是公开仓库，素材包括用户同意公开的项目资料。请保留原始文件版权及工程资料使用权限说明。

## 项目目标
将“AI 如何辅助视觉设计师完成实际工程三维动画”制作成一期具有专业科技节目质感的视频。参考影视飓风的专业讲述逻辑，但形成原创统一的视觉语言。

## 内容基础
- 案例：隧道深埋中心水沟开槽法施工工艺验证动画。
- 传统制作方式：Blender 建模、UE 渲染、动画与镜头制作。
- AI 辅助工作：用户通过与 AI 反复对话完成三维建模和动画过程；工作区为双电脑。
- 叙事反差：原本需要数周的建模与三维动画制作任务，在 AI 辅助下显著缩短周期。具体口播数据在最终剪辑前以项目记录核对。
- 内容平台：小红书等；当前选择 16:9 横屏母版。

## 已确定的视频语言
1. **故事先行**：问题 / 时间反差 / 实操证据 / 结果。
2. **16:9 电影感科技解说**：克制、留白、深蓝灰色系、精确排版和动效。
3. **主画面优先**：讲观点时大标题，讲操作时放大工作区录屏，讲成果时全屏三维动画。
4. **真人口播辅助**：出镜不必始终固定右下角，可根据叙事切换。
5. **五个关键节点**：开场悬念、挑战背景、AI 实操、流程对比、结果交付。

## 目录约定
- `docs/`：项目说明、脚本、分镜、交接与聊天记录。
- `assets/keyframes/`：视频关键帧参考图。
- `assets/prototypes/`：HTML 可编辑动态模板。
- `assets/videos/`：17 秒动态分镜、正式样片、原始录屏与动画源视频。
- `packages/`：可复用模板完整包。
